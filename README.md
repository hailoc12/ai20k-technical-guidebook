# AI20K Technical Guidebook

## Nội dung

10 chương covering toàn bộ quy trình xây dựng AI Agent:

1. Lời mở đầu — Mục tiêu và cách sử dụng
2. Khởi tạo dự án từ Template
3. Thiết kế kiến trúc hệ thống
4. Xây dựng AI Agent với LangGraph (chương trọng tâm)
5. Phát triển API với FastAPI
6. Giao diện người dùng (Next.js + Streamlit)
7. DevOps và Triển khai (Docker, CI/CD, deploy)
8. Kiểm thử và Đánh giá
9. Nộp bài Demo Day
10. Tài nguyên học tập
